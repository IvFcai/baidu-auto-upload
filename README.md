# 百度视频批量上传

这是一个基于 Playwright 的本地自动化脚本。它会使用 Google Chrome 打开百度营销账户首页，在“全部广告账户”中按账户名称搜索，再用账户 ID 锁定目标行并点击“电商推广”，然后进入“资产中心 → 视频库 → 上传视频”。程序从指定文件夹读取视频，默认每批 12 个，等待页面本批稳定后继续下一批。

Windows 安装包的构建、交付文件、技术栈和发布检查见 [WINDOWS_RELEASE.md](WINDOWS_RELEASE.md)。

现在提供深色玻璃质感桌面 GUI，适合直接查看账户、批次、进度和实时日志。桌面应用使用 Google Chrome 自动完成账户导航和上传。

## 发布安装包

普通用户不需要安装 Node.js、npm 或 Playwright。发布者在开发机执行：

```powershell
npm install
npm test
npm run dist
```

构建产物位于 `dist/`，主要文件为 `百度视频批量上传 Setup.exe`。安装器采用当前用户安装，不要求管理员权限，并创建桌面和开始菜单快捷方式。

目标电脑仍需预先安装 Google Chrome。应用启动时会检查 Chrome；找不到时会提示并打开官方 [Chrome 下载页](https://www.google.com/chrome/)。Chrome 不会被捆绑进本应用。

## 使用

### 桌面 GUI（推荐）

安装 `Setup.exe` 后，从桌面或开始菜单打开“百度视频批量上传”。

在界面中为账户选择视频文件夹，确认账户名称和 ID，设置每批数量后点击该账户的“上传视频”。GUI 会为该账户打开独立 Google Chrome，并严格按账户首页路径进入视频库。

视频按文件名排序后每批默认 12 个依次加入上传面板；追加批次只通过面板底部 `+` 添加，不覆盖前一批。页面稳定后，程序会删除带“重复上传视频”、上传失败、校验失败或解析失败标记的视频条目内的 `×`，随后对剩余成功视频自动点击“确定”。如果全部视频失败，程序不会点击“确定”，并保留 Chrome 页面供检查。

首次运行时请在自动打开的 Chrome 中扫码登录，并让程序继续进入“视频库 → 上传视频”。日志出现“百度登录状态已加密保存”后，后续重启会自动恢复登录。登录状态、Chrome profile、账户配置和调试文件保存在当前 Windows 用户的应用数据目录，不写入安装目录，也不会把 Cookie 或 token 以明文写入项目文件。

通常位于：

```text
%APPDATA%\baidu-video-batch-uploader\
```

新版本发布时，用户下载新的 `Setup.exe` 直接覆盖安装即可；本机账户配置和登录态会保留。卸载安装程序不会主动删除这些用户数据，便于重新安装后继续使用。

首版安装包未配置 Windows 代码签名，首次运行可能显示 SmartScreen 的“未知发布者”提示。确认安装包来源可信后选择继续即可。

如果百度服务器主动使会话过期、账号被退出或在其他设备触发安全验证，仍需重新扫码一次；扫码后程序会自动覆盖保存最新登录状态。

### 命令行

```powershell
node .\bin\baidu-auto-upload.js --folder "D:\\videos"
```

也可以省略 `--folder`，运行时输入路径：

```powershell
node .\bin\baidu-auto-upload.js
```

常用参数：

- `--batch-size 12`：修改批次大小，默认 12。
- `--account-id 88193126`：用于校验目标账户 ID，默认 `88193126`。
- `--account-name "baidu-nt-恰青春普化21"`：账户搜索词。百度这里搜索的是账户名称，不是 ID；默认账户已使用截图中的名称。
- `--recursive`：同时扫描子文件夹。
- `--profile .baidu-profile`：保存登录态的浏览器用户目录。
- `--chrome-path "C:\\Program Files\\Google\\Chrome\\Application\\chrome.exe"`：指定 Chrome 可执行文件路径；通常无需设置。
- `--input-selector "input[type=file]"`：页面控件变化时指定文件输入选择器。
- `--wait-minutes 15`：单批最长等待时间。
- `--direct`：跳过账户导航，直接打开默认视频库 URL（用于页面导航异常时排查）。

命令行入口主要用于开发和排查，不是普通用户的发布入口。首次运行需要在打开的浏览器中手动登录百度账号；上传期间不要关闭浏览器或切换到其他账号。

## 部署边界

本项目是本地桌面应用，不需要服务器或数据库。视频从用户选择的本地目录读取，Chrome 和 Playwright 在本机运行，每个 Windows 用户维护自己的百度登录状态。

只有在需要多人共享任务、远程控制、定时调度、统一日志或权限审计时，才需要另行设计服务器和数据库架构。
